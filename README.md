# Storage PaaS

Plataforma web de almacenamiento de archivos como servicio desarrollada
como proyecto de Ingeniería de Software.

## Tecnologías

### Frontend
- React

### Backend
- Django
- Django REST Framework

### Base de datos
- PostgreSQL
- Supabase

### Almacenamiento
- MinIO (S3 Compatible)

### Infraestructura
- Docker

### Gestión
- Git / GitHub
- Trello

## Arquitectura

El sistema utiliza una arquitectura Cliente-Servidor.

El backend está desarrollado como un Monolito Modular organizado
mediante Arquitectura por Capas.
